# What a Hugging Face Space installs. It cannot install this project itself:
# Spaces mount only this file into the build and run pip before the repo exists,
# so a `.` line resolves to an empty directory and fails. The deploy therefore
# stages the package at the Space's root, where Python imports it without an
# install, and this file lists what that package needs at runtime.
#
# Only the app's own import path (graph7ph.app -> db, explore, query, render,
# trends) is needed here. pydantic and requests belong to fetch and build, which
# the Space never runs. plotly draws the trend tab's line charts (gr.Plot): the app
# imports it directly, so it is declared here. Versions are exact and must move with
# uv.lock: a Ladybug release can change the on-disk storage format, and the app has
# to read an artifact the same version built. gradio matches the version the Space
# card declares as its SDK.
#
# pandas is here for the same reason as plotly, though nothing in the app calls it:
# `graph7ph.app` imports it at module load to warm it before any request thread
# runs, which is what stops a figure-building thread from meeting a half-initialised
# module and painting a red error box over the Trends charts (see the note at the
# import). gradio happens to pull it in too, but this app's own guard cannot rest on
# another package's dependency list, and the failure it prevents lands on a cold
# start, which is every first visit to a sleeping Space (issue #197).
ladybug==0.18.2
gradio==5.50.0
plotly==6.9.0
pyvis==0.3.2
pandas==2.3.3
